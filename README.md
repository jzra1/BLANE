# BLANE (Biological Adaptive Nutrition Engine)

BLANE is an Adaptive Nutrition Recommendation System Integrating Real-Time Health Data and Local Food Availability. It tailors food recommendations and portions to users in Tarlac City, Philippines, by analyzing real-time health data, budget, and local market inventory.
